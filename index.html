Configura la lectura de facturas (una sola vez)

  1. Abre aistudio.google.com/apikey e inicia sesión con tu cuenta de Google.
  2. Toca Crear clave de API (Create API key) y cópiala.
  3. Pégala aquí y toca Guardar.

La clave se guarda solo en este celular. Es gratis y no necesitas tarjeta.
